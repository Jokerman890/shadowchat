# ShadowChat

ShadowChat ist ein natives iOS-/Android-Monorepo für einen sicheren
Premium-Messenger mit gemeinsamem Rust-Core und klaren Plattformgrenzen.

## Codex starten

Das Repository ist für Codex initialisiert. `AGENTS.md` enthält die
Repository-Regeln; plattformspezifische Regeln liegen unter `apps/ios/` und
`apps/android/`.

```powershell
codex -C "C:\Users\tinab\OneDrive - MSFT\Dokumente\SchadowChat"
```

Arbeitsstart:

1. `AGENTS.md` lesen.
2. `docs/PROJECT-TODO.md` öffnen.
3. Ein Arbeitspaket auswählen.
4. Relevante Architektur- und Qualitätsdokumente lesen.
5. Implementieren und mit den vorgesehenen Checks verifizieren.

Siehe `docs/README.md` für alle Produkt-, Architektur-, Design- und
Qualitätsdokumente.
